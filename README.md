# GRILLE · 法语单词

TCF 法语词汇练习，例句取材于一级方程式。纯静态网页，不联网，进度存在本机浏览器。

## 怎么发布

1. 新建一个 GitHub 仓库（公开）
2. 把这个文件夹里的**全部内容**上传到仓库根目录
3. 仓库 Settings → Pages → Source 选 `main` 分支、`/ (root)` 目录
4. 等一两分钟，得到网址 `https://<用户名>.github.io/<仓库名>/`
5. 手机浏览器打开 → 分享 → 添加到主屏幕

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 应用本体，所有词库和逻辑都在里面 |
| `manifest.json` | 告诉手机把它当成 app 打开（全屏、无地址栏） |
| `icon-192.png` `icon-512.png` | 安卓主屏幕图标 |
| `apple-touch-icon.png` | iPhone 主屏幕图标 |
| `probe/index.html` | 存储测试页，网址是 `.../probe/` |

## 更新版本

只替换 `index.html`，网址不变，**学习进度不会丢**。
